# Pepveri — Auto Spare Parts (B2B Export Site)

Official website of **Pepveri Auto Parts** — a professional B2B auto spare parts
exporting partner connecting certified Chinese manufacturers with buyers worldwide.

Live pages: `index.html` (Home) · `products.html` · `oem-odm.html` · `about.html` (incl. RFQ form) · `news.html`

## Repository structure

```
/                 ← Auto parts site (current, active)
├── index.html
├── products.html
├── oem-odm.html
├── about.html
├── news.html
├── css/  js/  images/
└── legacy/      ← Previous (peptide) website — archived, not deleted
```

- The **root** serves the current auto parts website.
- The previous peptide site is fully preserved in **`/legacy`** (reachable at `/legacy/index.html`)
  and additionally snapshotted on the **`legacy-peptide`** branch.
- To restore the old site, restore files from `legacy/` or the `legacy-peptide` branch.
